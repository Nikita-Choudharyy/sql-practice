# SQL for Data Science & Analytics

Welcome to my SQL learning repository! This space is dedicated to tracking my journey in mastering SQL, from core relational database foundational concepts to complex data retrieval techniques used in Data Science and Machine Learning pipelines.

## 📌 Repository Structure & Roadmap

The repository is structured into organized folders, where each folder contains targeted SQL scripts (`.sql`) and a detailed topic breakdown.

### 🗂️ Modules Breakdown

1. **`01_DDL_Basics/`** (Data Definition Language)
   - Creating databases and tables
   - Modifying structures using `ALTER`, `TRUNCATE`, and `DROP`
   - Implementing Key constraints (`PRIMARY KEY`, `FOREIGN KEY`, `UNIQUE`, `CHECK`)

2. **`02_DML_Operations/`** (Data Manipulation Language)
   - Inserting clean records into tables
   - Modifying and cleaning data using `UPDATE` and `DELETE`

3. **`03_Basic_Queries/`** (Data Query Language - Foundational)
   - Retrieving data using `SELECT` and `DISTINCT`
   - Filtering records with `WHERE`, `LIKE`, `IN`, and Logical Operators (`AND`, `OR`)
   - Sorting and limiting results with `ORDER BY` and `LIMIT`

4. **`04_Advanced_SQL/`** (Analytical Operations)
   - Grouping data and filtering aggregates (`GROUP BY`, `HAVING`)
   - Merging datasets using multiple `JOINS` (INNER, LEFT, RIGHT, FULL)
   - Advanced analytical queries using Window Functions

---

## 🎯 Learning Goals
- Write optimized and clean SQL queries.
- Build a strong foundation in database normalization and design.
- Prepare production-ready SQL scripts for data analytics pipelines.

*Note: All data exploration scripts here focus purely on relational database concepts. Python/Pandas integrations are maintained in separate dedicated repositories to ensure structural clarity.*
